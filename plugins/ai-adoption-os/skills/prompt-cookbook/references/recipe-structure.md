# Recipe structure

Eight to twelve recipes, weighted toward the roles with the most repetitive work.

```
# Prompt Cookbook: [Company Name]

**Prepared:** [date]
**Built for:** [roles]
**Works in:** [their AI tool]

## How to use this

Copy the recipe, replace the parts in [brackets], paste it into [tool]. Compare
what you get against the example. Three sentences, no tutorial.

**Off limits:** [the data constraints named in the interview, stated once, up front.]

---

## [Role name]

### [The job this does, named as a job]

**Who runs it:** [role] · **How often:** [cadence]

**Prompt**
```
[The prompt. Placeholders in [brackets]. Self-contained: assumes no system prompt,
no prior context, nothing the person will not have.]
```

**What good looks like**
[One short example of correct output. Trimmed, not a full page.]

**When it goes wrong**
[The most likely failure and what to check. Every recipe has one.]

**Do not put in this prompt:** [specific constraint if this recipe touches
restricted data. Omit the line entirely if it does not.]

---

[Repeat per recipe, grouped by role]

---

*Created by Blane Warrene, blanewarrene.com*
```
